# Creative Route Selection

Mood Weaver should not jump straight from brief to final moodboard. It should first identify whether the visual direction is already resolved. If unresolved, generate a small set of visual routes and recommend the strongest one. If resolved, produce one core world with controlled variations.

## Route Count

Create up to 3 routes maximum only when the brief is unresolved:

- Route 1: safest / most direct answer to the brief
- Route 2: more emotional or atmospheric interpretation
- Route 3: more surprising, social, or memorable interpretation

If the brief is already narrow or Story Weaver has selected a direction, create one route and two or three controlled variations.

## Route Format

```md
## Route Name
- One-line concept:
- Emotional promise:
- Strategic job:
- Visual world:
- Script approach:
- Moodboard implication:
- Why it works:
- Risk:
- the creative lead fit:
```

## Selection Criteria

Recommend the route that best balances:

- clear assignment fit
- the creative lead taste
- emotional specificity
- visual distinctiveness
- script strength
- visual-world coherence
- platform/job fit
- feasibility for Runway or real production

## Anti-Pattern

Do not create three routes that are only palette swaps. Routes should differ in concept, emotional path, script-support approach, or visual logic. Once strategy is settled, do not reopen it.
